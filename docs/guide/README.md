# MarkCopy user guide

MarkCopy turns VS Code into a document workspace where you read any file, make light edits, and hand it off (rich paste, Word, PowerPoint, PDF) without leaving the editor.

- [Getting started](getting-started.md): install, open a file, the Show Preview / Show Source swap, side-by-side preview, editor associations, and auto-preview.
- [Markdown preview](markdown.md): live preview, themes, Mermaid, math, local images, and edit mode.
- [Copying out](copy.md): rich text, per-element right-click copy, raw Markdown, and how the copy works.
- [Export](export.md): Save as PDF, Save as Word, and Save as PowerPoint.
- [Spreadsheets](spreadsheets.md): the editable CSV and TSV grid and the Excel preview.
- [Documents](documents.md): Word, PowerPoint, PDF, and LaTeX previews.
- [Media](media.md): image, GIF, video, audio, and STL 3D previews.
- [Commands and settings](settings.md): the command list, every setting, and the in-preview Preferences menu.

For the full reference of every copy action, see the [Copy Matrix](../COPY-MATRIX.md).
